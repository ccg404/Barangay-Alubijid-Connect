# Barangay-Alubijid-Connect

A simple web application for the local government of Alubijid. Residents can access their bills, community reports, and more.

<img width="1919" height="951" alt="image" src="https://github.com/user-attachments/assets/21806f9e-a222-413f-86f5-f35b6c1d014f" />

## Run

Serve this folder over HTTP (for example, `python -m http.server 8000`) and open `http://localhost:8000`. The app uses native JavaScript modules and cannot be launched reliably from a `file://` URL.

## Tests

Run `node --test` from this folder.
